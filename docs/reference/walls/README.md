# Reference: Walls

Reference photos for the **walls campaign** (a wall = a region whose
footprint is the wall's plan, with a texture family applied to its faces
and top).  Source: Wikimedia Commons (public/permissive).  See also the
commercial-tile cliff idiom already in `docs/rocks/`:
`rocks-reference-stairs-grotto.png` (stratified cliff faces),
`rocks-reference-high-waterfall-cliff.png` (cliff columns + boulder
caps), `rocks-reference-big-rock-outcrop.png` (fluted sides, plateau).

## Texture references (primary)

| File | What it shows |
|---|---|
| `drystone-fieldstone-detail.jpg` | **The fieldstone texture.** Rough courses of varied rounded/angular stones, deep shadow joints (no mortar), size variety with occasional throughstones, small pinning stones in gaps. |
| `brick-worn.jpg` | **The brick texture.** Running bond, eroded mortar joints (negative relief), spalled and broken bricks breaking the grid, a few missing (put-log holes) — the grid is *imperfect*, that's the whole read. |
| `quarry-rock-face.jpg` | **The rocky-cliff texture.** Stratified near-vertical rock: strong horizontal bedding at multiple thicknesses, vertical joint fractures, benches with rubble. Matches the commercial cliff idiom. |
| `church-coursed-stone.jpg` | Thin-stone herringbone/diagonal coursing variant; dressed quoins around openings. A stretch texture, shows coursing can carry direction. |

## Recurring vocabulary (for the interview)

1. **A wall is two faces, a core, and a top.** Faces carry the texture;
   the top is its own surface (cap course, walkway, crenellations, or
   broken rubble core).  Texture wraps ends and corners.
2. **Courses are horizontal.**  Every masonry family reads as horizontal
   rows first — even rough fieldstone.  The cliff face reads as bedding
   strata: same rule, geological scale.
3. **Joints are negative relief.**  Mortar recesses / shadow gaps between
   stones are what paint washes need; stones bulge slightly proud, each a
   little different (the E10–E14 stone lessons apply per-stone).
4. **The grid must be broken to read real** — spalled bricks, a missing
   stone, a ragged top line, size variety within courses.
5. **Walls sit into the ground** — grass/soil laps the base; ruins
   shed rubble at the foot (ties into the scatter-stone system).
