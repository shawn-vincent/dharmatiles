## The Bug

In the **debug leaf STLs** (generated by `src/scripts/generate-debug-leaf-placement-simplified-stl.py`),
the leaf walls extend from the leaf perimeter all the way down to the sphere surface (correct).

In the **1x1-grass-tree+water tile** (and all tiles with tree foliage), the leaf walls were
**short 0.75 mm stubs** rather than reaching the foliage cluster surface.

---

## Root Cause

`solidify_leaf()` in `leaf.py` embeds leaf roots by raycasting each perimeter vertex along
`-local_n` (the leaf's outward normal at that vertex) into the parent mesh, then placing the
root vertex `embed_mm = 0.75 mm` past the hit.  If a ray **misses** the parent mesh, it falls
back to `root = perim + 0.75 mm * ray_dir` — a stub only 0.75 mm from the perimeter.

**Debug STL path** (`place_leaf_on_sphere` in `leaf.py:1337`):
1. `find_contact_angle_for_sphere()` binary-searches for the rotation that presses the leaf
   **tip** against the sphere surface.
2. This rotates the entire leaf frame inward so the leaf follows the sphere curvature.
3. All perimeter vertices are then close to the sphere; raycasts succeed; walls reach the surface.

**Tree foliage path** (`_emit_leaf` inside `_build_foliage_cluster_mesh` in `trees/mesh.py`):
- Previously called `build_leaf_surface` + `solidify_leaf` with **no contact angle search**.
- The leaf's arch (30°), curl (20°), and lift push the tip far above the small 5.5 mm cluster.
- Many perimeter-vertex rays miss the cluster entirely → stub walls.

---

## Foliage Cluster Shape (important caveat)

The foliage cluster is **not a sphere**. It is a noised icosphere deformed along the branch
Bezier spine into a back-hemisphere → cone → forward-dome profile. However, **locally** at
each leaf placement point the surface is well-approximated by a sphere of radius
`cluster_radius_mm` (the ring radius at that arc position, returned by `_cone_point` /
`_dome_point`). The local ring centre is `base_pos - cluster_radius_mm * up_hint`.

The contact angle only needs to be approximately right (to within a few degrees) because:
- `solidify_leaf` does the precise embedding via raycast into the **real** noised cluster mesh.
- The contact angle just ensures the leaf is tilted enough that the perimeter-vertex raycasts
  actually hit the cluster.

def _emit_leaf(
    base_smooth: np.ndarray,
    radial: np.ndarray,
    key,
    cluster_radius_mm: float = float("inf"),
) -> None:
    if cluster_radius_mm < 1.0:
        return

    up_hint = _safe_norm(radial)

    disp_base = float(
        _foliage_gaussian_noise(base_smooth[None, :], edge_id, bark_seed)[0]
        + _foliage_coarse_noise(base_smooth[None, :], edge_id, bark_seed)[0]
    )
    base_pos = base_smooth + up_hint * (disp_base - noise_peak)

    _grav = np.array([0.0, 0.0, -1.0])
    _proj = _grav - float(np.dot(_grav, up_hint)) * up_hint
    _plen = float(np.linalg.norm(_proj))
    if _plen < 1e-6:
        _arb = np.array([1.0, 0.0, 0.0])
        if abs(float(np.dot(_arb, up_hint))) > 0.9:
            _arb = np.array([0.0, 1.0, 0.0])
        T0 = _safe_norm(np.cross(up_hint, _arb))
    else:
        T0 = _proj / _plen

    yaw    = (2.0 * _hash01(bark_seed, "leaf-yaw", edge_id, key) - 1.0) * jit
    T0_rot = np.cos(yaw) * T0 + np.sin(yaw) * np.cross(up_hint, T0)
    T0     = _safe_norm(T0_rot)

    lseed = _hash01_int(bark_seed, "base-leaf", edge_id, key)

    # --- CACHE LOOKUP ---
    # The contact angle depends only on cluster_radius_mm and the fixed leaf
    # geometry params (same for all leaves in this cluster call).  Look it up
    # or compute analytically via _contact_angle_for_sphere.
    rr_key = round(float(cluster_radius_mm), 4)
    if rr_key not in _ca_cache:
        _ca_cache[rr_key] = _contact_angle_for_sphere(
            float(cluster_radius_mm), **_ca_leaf_kwargs,
        )
    contact_angle = _ca_cache[rr_key]

    # Apply contact angle to frame
    c_ca = float(np.cos(contact_angle))
    s_ca = float(np.sin(contact_angle))
    tangent   = _safe_norm(T0 * c_ca - up_hint * s_ca)
    up_placed = _safe_norm(up_hint * c_ca + T0 * s_ca)

    leaf_surface_kwargs = dict(
        length_mm=float(leaf_length_mm),
        width_mm=float(leaf_width_mm),
        thickness_mm=float(leaf_thickness_mm),
        fold_angle_deg=float(leaf_fold_angle_deg),
        inner_curve=float(leaf_inner_curve),
        outer_curve=float(leaf_outer_curve),
        curl_deg=float(leaf_curl_deg),
        lift_mm=float(leaf_lift_mm),
        seed=lseed,
    )
    try:
        leaf_surf = build_leaf_surface(
            base_pos=base_pos, tangent=tangent, up_hint=up_placed,
            **leaf_surface_kwargs,
        )
        solid, _ = solidify_leaf(leaf_surf, up_placed, parent_mesh=cluster_mesh)
    except (RuntimeError, ValueError):
        return
    if len(solid.vertices) > 0:
        leaf_parts.append(solid)

### Step 3: Analytical contact angle function (already added to mesh.py, but double-check)

Added `_contact_angle_for_sphere()` as a module-level function before `_build_foliage_cluster_mesh`.
It derives the contact angle from the closed-form tip-touching constraint:

```
contact_angle = arccos(−D / 2R) − atan2(L_comp, N_comp)
```

where:
- D = |v_tip − base| (tip displacement magnitude, from `compute_leaf_geometry` at lift=0)
- L_comp = component of tip displacement along leaf longitudinal axis L
- N_comp = component of tip displacement along leaf normal axis N
- R = cluster_radius_mm (local sphere radius)

The derivation: rotating the leaf frame by θ around the lateral axis T through base_pos,
the tip position is `tip(θ) = base + (L·cosθ + N·sinθ)·T0 + (R + N·cosθ − L·sinθ)·up`.
Setting `|tip(θ) − local_center|² = R²` and expanding gives:

```
N_comp·cosθ − L_comp·sinθ = −(L_comp² + N_comp²) / (2R)
```

which is `A·cosθ + B·sinθ = C`, solved analytically. T_comp = 0 by leaf bilateral
symmetry (tip lies in the L–N plane), so D = √(L² + N²) is exact.

**Why this is valid:**
- The contact angle is invariant under rotation of T0 around up_hint (local sphere symmetry).
- So it depends only on `(cluster_radius_mm, leaf_geometry_params)`.
- Within one `_build_foliage_cluster_mesh` call, leaf_geometry_params are fixed.
- Only ~10–20 distinct values of cluster_radius_mm exist per cluster (one per row band).
- With caching: ~10–20 calls to `_contact_angle_for_sphere` instead of ~3400 binary searches.
