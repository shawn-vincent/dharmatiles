Error code · a mistake in the document

dt::tile-name

A tile takes no name: its file name is its name

What to do

Remove the name from the tile line and name the file instead.

The message itself says it for your case, at the line it is about. In a terminal, dharmatiles explain dt::tile-name prints this page's summary from your own copy of the docs.

Broken, then fixed

This document gives dt::tile-name:

dharmatiles version=1
tile pond size="1x1" {
    stack { dirt }
}

Mended, it builds:

dharmatiles version=1
tile size="1x1" {
    stack { dirt }
}
