Error code · a mistake in the document

dt::group

That control is a group of controls, not a value.

What to do

Write the group's own controls on its line: leaf length="4dmm" width="3dmm".

The rule

A control that holds only sub-controls, written as properties on its own line: leaf length="4.5dmm" width="3dmm".
