dt::tile

A file holds one tile

What to do

Put each tile in its own file.

The message itself says it for your case, at the line it is about. In a terminal, dharmatiles explain dt::tile prints this page's summary from your own copy of the docs.

Broken, then fixed

This document gives dt::tile:

dharmatiles version=1
tile size="1x1" {
    stack { dirt }
}
tile size="1x1" {
    stack { dirt }
}

Mended, it builds:

dharmatiles version=1
tile size="1x1" {
    stack { dirt }
}
