What to do

Check the spelling against the element's page; the message names the nearest control.

Broken, then fixed

The rule

Every mistake gets a message with a stable code (such as dt::unit), the line it is on with the spot underlined, and a hint that says what to write instead. The program reads on past a mistake, so all of a file's mistakes come together. dharmatiles check my-tile.dtile reports them without building (it takes --system, --printer and --seed like build, so a mistake that only shows on OpenLOCK is caught too); the preview shows them beside the tile.
