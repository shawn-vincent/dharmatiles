Error code · a mistake in the document

dt::printer

A printer profile is not found or does not read.

What to do

dharmatiles printers lists them; the message says what is wrong with a profile.

The rule

Put a file in printers/ beside your tiles ($DT_HOME, else ~/dharmatiles): printers/shed-voron.dtile is shed-voron, and printers/mine/ender.dtile is mine/ender. A profile of yours with the name of a library one replaces it. It may start from a library one:
