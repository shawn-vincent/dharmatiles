Error code · a mistake in the document

dt::unknown-node

That line is not one this kind of document holds.

What to do

Check the spelling and where the line goes; the message says what is allowed here.

The rule

A line this kind of document does not hold at this place: a plates line holds pin lines and nothing else, a tile holds the nodes of section 1. The message says what is allowed there.
