Error code · a mistake in the document

dt::nesting

That entry cannot go inside this one.

What to do

Move it to the stack, or inside an element that takes it.

The rule

An entry was written inside one that does not take it. A pin goes inside a body, a thing inside a scatter; terrain goes in the stack.
