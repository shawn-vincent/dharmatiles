Error code · the program failed, not the document

dt::inventory

The inventory file cannot be read or written.

What to do

Mend inventory.dinv, then dharmatiles inventory relink <old> <new>.

The rule

The inventory is a KDL v2 document called inventory.dinv, in your tiles folder ($DT_HOME, else ~/dharmatiles) beside the tiles. It has its own extension because it is not a tile. Nothing is made until the first line is written: with no file there is no inventory yet, and every piece prints.
