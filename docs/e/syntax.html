Error code · a mistake in the document

dt::syntax

Documents are KDL v2: a bare true, false or null is KDL v1

What to do

Write the keyword with a hash: #true, #false, #null.

The message itself says it for your case, at the line it is about. In a terminal, dharmatiles explain dt::syntax prints this page's summary from your own copy of the docs.

Broken, then fixed

This document gives dt::syntax:

dharmatiles version=1
tile size="1x1" {
    stack { dirt clods=null }
}

Mended, it builds:

dharmatiles version=1
tile size="1x1" {
    stack { dirt clods=none }
}
