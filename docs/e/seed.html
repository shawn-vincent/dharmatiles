dt::seed

A tile's seed is a whole number from 0.

What the program says

dt::seed

  × a seed is a whole number from 0 to 9223372036854775807, not -3
   ╭─[example.dtile:2:22]
 1 │ dharmatiles version="1.0.0"
 2 │ tile size="1x1" seed=-3 {
   ·                      ─┬
   ·                       ╰── out of range
 3 │     stack { dirt }
   ╰────
  help: explain: https://shawn-vincent.github.io/dharmatiles/e/seed
        offline: dharmatiles explain dt::seed

What to do

Write seed= with a whole number, 0 or more.

Broken, then fixed

The rule

tile size="1x1" seed=97 { … } sets it; a tile that writes none is built with the seed the build is asked for (dharmatiles check --seed N, or the seed control of a card or the editor). A negative or fractional seed is refused.
