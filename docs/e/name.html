Error code · a mistake in the document

dt::name

A plain name is declared twice or is a word of the language.

What to do

Pick another name; override replaces a $ name the context already has.

The rule

A plain name (a let, a param) may not be a word of the language; it is a dt::name error that names the word and its kind.
