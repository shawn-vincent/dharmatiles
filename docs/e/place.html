Error code · a mistake in the document

dt::place

That place is not one the element can use.

What to do

Write a place the element takes: a point, a line or a region, as its page says.

The rule

Each element takes the kinds of place that mean something to it and refuses the others with dt::place or dt::type and a help line: a second at= on one entry, a thing given a line, a scatter given a point, a nesting that has no meaning. The message names what the element accepts.
