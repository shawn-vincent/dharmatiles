Error code · a mistake in the document

dt::id

Another entry of that element already has that id=.

What to do

Give every entry of an element its own id.

The rule

  • seed=: pins this entry’s own randomness while the tile seed changes everything else. The tile level’s seed row says which entries do this (wall keeps its own seed (15)), since rolling the tile seed will not change them.
  • id=: a name for the entry, for edits and diagnostics.
  • weight=: only on a child of a scatter, its share of the mix.
  • The place words its element accepts (section 5).
