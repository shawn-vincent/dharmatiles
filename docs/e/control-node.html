Error code · a mistake in the document

dt::control-node

A control written as its own line has no block.

What to do

Write the control as name=value on the element's line, or give the line a value.

The rule

Documents are KDL v2, a small, readable configuration language, checked by the program against the tile language, so every error message is written for you, at the line it is about.
