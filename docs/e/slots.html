Error code · a mistake in the document

dt::slots

A piece needs more filaments than the printer has slots.

What to do

Use fewer materials, or print it on a printer with more slots.

The rule

Single colour writes every piece in one filament with no paint on any triangle, so it fits any printer. Multicolour keeps each material in its own filament, painted per triangle, the way the single-tile 3MF is.
