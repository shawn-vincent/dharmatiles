Error code · a mistake in the document

dt::header

The header line takes version= and nothing else

What to do

Write just dharmatiles version=1, with no children and no other settings.

The message itself says it for your case, at the line it is about. In a terminal, dharmatiles explain dt::header prints this page's summary from your own copy of the docs.

Broken, then fixed

This document gives dt::header:

dharmatiles version=1 {
    note
}
tile size="1x1" {
    stack { dirt }
}

Mended, it builds:

dharmatiles version=1
tile size="1x1" {
    stack { dirt }
}
