Error code · a mistake in the document

dt::header-first

The header line must be the first node of the file

What to do

Move dharmatiles version=… above everything else.

The message itself says it for your case, at the line it is about. In a terminal, dharmatiles explain dt::header-first prints this page's summary from your own copy of the docs.

Broken, then fixed

This document gives dt::header-first:

tile size="1x1" {
    stack { dirt }
}
dharmatiles version=1

Mended, it builds:

dharmatiles version=1
tile size="1x1" {
    stack { dirt }
}
