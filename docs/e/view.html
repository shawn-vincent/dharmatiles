Error code · the program failed, not the document

dt::view

The view of a print list could not be prepared.

What to do

The message says why; mend the list or the tile it names.

The rule

Open a .dmap from a folder and the view shows the printer's bed as a translucent slab the pieces stand on (any excluded zones shaded on it) with the plate in view, and the panel changes to the plates' panel. The Tile, Map and Plates switch in the title bar names what you are working on: a document with placed pieces also opens as a map, and Print what’s missing there comes to the same plates. Looking down on the bed (Top), drag a piece to pin it where you drop it.
