dt::unknown-name

Nothing declares or sets that name

What to do

Check the spelling; the message names the nearest name.

The message itself says it for your case, at the line it is about. In a terminal, dharmatiles explain dt::unknown-name prints this page's summary from your own copy of the docs.

Broken, then fixed

This document gives dt::unknown-name:

dharmatiles version=1
tile size="1x1" {
    stack { dirt top="$grundHeight" }
}

Mended, it builds:

dharmatiles version=1
tile size="1x1" {
    stack { dirt top="$groundHeight" }
}
