Error code · a mistake in the document

dt::edge-range

A point on a side of the tile has a range, so each seed would put it somewhere else on the side.

What to do

Write the place alone, a seam such as n (halfway along the north side).

The rule

A point within 1 mm of a side but not on it is dt::near-edge, with a fix that moves it onto the side. A range on a point that lies on a side is dt::edge-range: it would draw a different place for each seed.
