Error code · a mistake in the document

dt::type

Kinds do not agree: a length mixed with a plain number, or a place of the wrong kind

What to do

Make both sides the same kind; the message says what to write.

The message itself says it for your case, at the line it is about. In a terminal, dharmatiles explain dt::type prints this page's summary from your own copy of the docs.

Broken, then fixed

This document gives dt::type:

dharmatiles version=1
tile size="1x1" {
    stack { dirt top="$dirtEdgeHeight + 20%" }
}

Mended, it builds:

dharmatiles version=1
tile size="1x1" {
    stack { dirt top="$dirtEdgeHeight + 2dmm" }
}
