Element · base

openlock

The OpenLOCK base, by Printable Scenery: a 1-inch (25.4 mm) grid of tiles joined side by side with separate clips that slide into T-shaped slots in the base walls, one slot per square on every edge.

On this page
  1. Building for it
  2. Reference

Building for it

dharmatiles build my-tile.dtile --system ol
dharmatiles build --all --system ol

Every size in the document scales with the square, like a photocopy: a 7 mm wall prints 5.08 mm thick. The printability floors (one line, one layer) never shrink.

The pocket is where the clip's head sits. It is open to the table from the bottom of the base, so the roof over it, 5.6 mm up at its two outer strips and 5.9 mm in the middle 14 mm, is bridged. The printer's bridge limit holds it with no support inside the slot.

Only the 25.4 mm version is built; the 25.0 mm metric variant does not tessellate with it. Full drawings: tile system.
