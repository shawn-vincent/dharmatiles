Element · base

openlock

The OpenLOCK base, by Printable Scenery: a 1-inch (25.4 mm) grid of tiles joined side by side with separate clips that slide into T-shaped slots in the base walls, one slot per square on every edge.

On this page
  1. Building for it
  2. Reference

Building for it

dharmatiles build my-tile.dtile --system ol
dharmatiles build --all --system both

Every size in the document scales with the square, like a photocopy: a 7 mm wall prints 5.08 mm thick. The printability floors (one line, one layer) never shrink.
