Element · library file

edges

The edge contract: what every tile does at its edges, so that neighbouring tiles butt with no step. Every tile uses it without a use line.

On this page
  1. Writing it
  2. Reference
  3. Notes

Writing it

// library/parts/edges.dtile
edges {
    ground level=edge           // ground meets every tile edge at the edge level (3.4 mm)
    water level=water           // water meets it at the water level, with a shared tide
}

Reference

LineMeans
groundEvery surface meets the tile edge at the edge level, 3.4 mm.
waterWater meets the tile edge at the water level, 2.6 mm, plus a shared tide: 0.6 sin(2π(s − 13.125)/17.5) mm along each edge, so two water tiles butt any way round.

The same contract is also written in the heights language, as the defaults block of the same file: the top and the pin at edges every dirt, floor and water body starts with (dirtEdgeHeight, floorEdgeHeight, waterEdgeHeight). A tile's own top replaces a default top, and its pins win over the default pin. See pin and heights.

Notes

Runs on an edge (walls, cliffs) end in the standard end section, so runs butt together too. See how tiles meet.
