printer

The printer profile. Every size an author writes scales with the system; these numbers never do. They are the floors nothing is built below: blade and leaf thickness, the least branch radius, print gaps, and the overhang the printability gate allows.

Writing it

// library/printers/default.dtile
printer default {
    line     0.45       // one extruded line, mm: the thinnest wall that prints
    layer    0.2        // one layer, mm
    overhang 55         // what every element aims for, degrees from vertical
    steepest 65         // small patches up to here (0.2 mm layer: 0.43 mm step, under a line)
    gap      0.2        // the narrowest gap that stays open, mm
}

Reference

ControlTakesDefaultMeans
linemm0.45One extruded line: the thinnest wall that prints.
layermm0.2One layer.
overhangdegrees55The overhang every element aims for, from vertical. Faces between it and steepest are the band: orange in renders, allowed up to 0.1% of the downward-facing area.
steepestdegrees65Past this, overhang is red: allowed up to another 0.1%, more fails. It must be past overhang, and no steeper than the angle at which a layer steps out one line (atan(line / layer): 66° for 0.45 and 0.2).
gapmm0.2The narrowest gap that stays open.
