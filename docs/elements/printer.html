Element · library file

printer

The printer profile. Every size an author writes scales with the system; these numbers never do. They are the floors nothing is built below: blade and leaf thickness, the least branch radius, print gaps, and the overhang the printability gate allows.

Writing it

dharmatiles version="1.0.0"

// library/printers/default.dtile
printer default {
    line     "0.45mm"   // one extruded line: the thinnest wall that prints
    layer    "0.2mm"    // one layer
    overhang "55deg"    // what every element aims for, from vertical
    steepest "65deg"    // small patches up to here (0.2 mm layer: 0.43 mm step, under a line)
    gap      "0.2mm"    // the narrowest gap that stays open
}

Reference

ControlTakesDefaultMeans
linelength (mm)0.45mmOne extruded line: the thinnest wall that prints.
layerlength (mm)0.2mmOne layer.
overhangangle (deg)55degThe overhang every element aims for, from vertical. Faces between it and steepest are the band: orange in renders, allowed up to 0.1% of the downward-facing area.
steepestangle (deg)65degPast this, overhang is red: allowed up to another 0.1%, more fails. It must be past overhang, and no steeper than the angle at which a layer steps out one line (atan(line / layer): 66° for 0.45 and 0.2).
gaplength (mm)0.2mmThe narrowest gap that stays open.

Notes

A printer's numbers are printed lengths and angles: mm and deg. sq, dmm and layer have no meaning here and are refused, and a bare number has no unit (dt::unit). See printing for the gate every build passes.
