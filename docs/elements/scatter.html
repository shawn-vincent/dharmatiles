Element · placement

scatter

More than one of a thing. A scatter says how many and where; its children say what. Rocks, stones, boulders, pebbles, trees and definitions whose stack is one thing can all be scattered.

Writing it

scatter in=pool count=2 { rock size="6..10" }                 // two rocks in the pool
scatter against=cliff per-square=55 reach=4 { stone }         // scree at the cliff's foot
scatter per-square=3 { stone weight=3; boulder }              // a mix, three stones to a boulder
dirt { scatter per-square=40 { pebble } }                     // inside a surface: lands on it

A scatter needs exactly one of count and per-square. reach needs against=; spread needs at=. With several children, each child's weight= is its share of the mix (default: equal). Every scattered thing keeps inside the tile and clear of other solids: it is nudged inward, never clipped.

Notes

against=
Gathers at the foot of that kind of thing: cliff, wall, rock or tree. Scattered against a cliff, rocks take the cliff's rock: that is scree.
mostly=
Skews every child's size range as lo + (hi − lo) × uk: small is k = 2, even k = 1, large k = ½.
inside a surface
A scatter written inside dirt or grass is placed on that surface, in its area.

A single thing never takes a count: tree count=3 is an error whose help says to use a scatter. See placement in the language guide.
