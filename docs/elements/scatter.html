scatter

More than one of a thing. A scatter says how many and where; its children say what. Rocks, stones, boulders, pebbles, flowers, trees and definitions whose stack is one thing can all be scattered.

On this page

  2. Reference

Writing it

scatter at=pool count=2 { rock size="6..10" }                 // two rocks in the pool
scatter at="foot(cliff)" perSquare=55 reach=4 { stone }         // scree at the cliff's foot
scatter perSquare=3 { stone weight=3; boulder }              // a mix, three stones to a boulder
dirt { scatter perSquare=40 { pebble } }                     // inside a surface: lands on it

A scatter needs exactly one of count and perSquare. reach needs at=foot(…). A scatter holds rocks or flowers, not a mix of the two. With several children, each child's weight= is its share of the mix (default: equal). Every scattered thing keeps inside the tile and clear of other solids: it is nudged inward, never clipped.

Notes

at=foot(cliff)
Gathers at the foot of that kind of thing: cliff, wall, rock or tree. Scattered at a cliff's foot, rocks take the cliff's rock: that is scree.
at=line
Spreads along a drawn line, an edge or an edge path, within reach mm either side of it (default 5 mm), to the ends of the line rounded. perSquare counts the line's length in squares. It builds for rocks, flowers and trees alike: scatter at=road count=3 reach=3 { tree size="26..32" }. A single thing at a line is refused (a line has no one place on it); a scatter is how several stand along one.
trees
A scatter of trees places every crown clear of the others (centres at least both crown radii and gap apart, default 1 mm), each trunk a crown radius in from the tile edge and clear of what already stands, then grows them one after another, each from its own seed. A tree is a heavy build: ask for few. If the crowns cannot all fit it is an error naming how many do, never fewer trees without a word.
count, perSquare
Take a weighted range: perSquare="low(2..8, 3)". Each whole number of a range is as likely as any other. See weighted ranges.
inside a surface
A scatter written inside dirt or grass is placed on that surface, in its area.

A single thing never takes a count: tree count=3 is an error whose help says to use a scatter. See placement in the language guide.
