Element · the document

tile

Every tile document holds exactly one tile. It names the tile, says how many squares it covers and which seed it grows from, and holds everything else: its levels, lines, regions and stack.

Writing it

tile water+grass size="1x1" seed=97 {
    about "Water in the lower half, a meadow bank in the upper."
    line shore wobble=5 { through "0,0.38" "1,0.42" }
    region pool { bounded-by shore; fill "0.5,0.25" }
    region bank { bounded-by shore; fill "0.5,0.75" }
    stack {
        dirt in=bank
        grass in=bank
        ground in=pool level="water - 2.2"
        scatter in=pool count=2 { rock size="6..10" }
        water
    }
}

Reference

WrittenTakesDefaultWhat it does
tile NAMEa name—The tile's name, shown in the preview and the build record. Required.
size="CxR""1x1"Squares across, then up. A square is 35 mm (DungeonBlocks) or 25.4 mm (OpenLOCK).
seed=a whole number1The root seed. Every element's randomness is keyed from it; dharmatiles build --seed overrides it.
abouta string—Free text: what the tile is.
levelsnames and mm—Levels this tile adds or overrides.
line—Lines, for divided tiles.
region—Areas bounded by lines.
stack—What the tile is made of. Exactly one.

Notes

Above the tile a file may have use lines. Anything else at the top level of a tile document is an error. Positions in the tile are in squares from the south-west corner, x east and y north. The build adds the DungeonBlocks or OpenLOCK base; the document never names it.

File names follow the tile-system naming: 1x1-water+grass.dtile.
