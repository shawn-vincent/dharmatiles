Element · the document

levels

Named heights in mm above the tile base. Four standard levels are in every document without a use line; a tile can add its own or override them. A level can be used anywhere a level is expected, alone or in an expression.

Writing it

tile cliff-run size="2x1" {
    levels foot=4                       // this tile's own
    stack {
        ground level="water - 2.2"      // an expression on a standard level
        dirt level=edge
    }
}

Reference

Standard levelmmMeaning
edge3.4Ground meets every tile edge here, so tiles butt with no step.
ground5Grass and soil regions.
water2.6The water level.
wall-top33.1The official wall top.

In a tile: levels NAME=MM … on one line. In a parts file: a block, one level per line, levels { foot 4 }. The standard ones come from library/parts/levels.dtile.

Notes

Like every size, levels scale with the system: at OpenLOCK's 25.4 mm square the edge level is 2.47 mm. A quoted value is a small expression: "water - 2.2", "wall-top / 2". See units, levels and scaling.
