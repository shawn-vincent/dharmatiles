Element · surface

flowers

Wildflowers: each one a thin dome on a column, ringed by petal domes on cones. Flowers stand before the grass is grown, so the grass grows round them, never through them.

Writing it

use "parts/grass" lawn

tile grass-flowers size="1x1" seed=7 {
    stack {
        dirt
        flowers per-square=4 petals=5 radius=2.5
        lawn
    }
}
