point

A named point on the tile, counted from the north-west corner. Pins, things, lines and regions use it by name.

On this page
  1. Writing it
  2. Reference
  3. Notes

Writing it

point knoll "(0.28sq, 0.28sq)"
line path { through southCenter knoll northCenter }
stack { base; dirt { pin top="$groundHeight + 4dmm" at=knoll } }

Reference

WrittenTakesWhat it does
point NAMEa nameIts name. Required. camelCase, declared once.
the value"(across, down)", point(…) or polar(…)Across from the west edge, then down from the north edge, each half a length with its unit ("(0.28sq, 0.28sq)") or a share of the frame ("(50%, 0.25sq)"). Required. Not a range: a declared point is fixed; a range goes where the point is written, in a line's through or a region's fill.

Built in on every tile, with no declaration: southWestCorner southCenter southEastCorner westCenter center eastCenter northWestCorner northCenter northEastCorner. The four edge lines are northEdge eastEdge southEdge westEdge, and edges is all four; tile is the whole tile, which is also what no at= means.

Notes

A point may also be written where a place is wanted, as the literal "(0.28sq, 0.28sq)": at="(0.28sq, 0.28sq)", fill "(0.5sq, 0.75sq)", through "(0sq, 0.62sq)". Naming the frame makes the point explicit: point($tile, 25%, 75%) is a quarter across and three quarters down the tile, and polar($tile, 40%, 90deg) is 40% of the way out from the middle, straight down (0 is east, turning towards the south). A point written inside a pin of a body that acts in a named region is in that region's own frame, and a point outside it is dt::point. A point is flat: it says where, never how high.
