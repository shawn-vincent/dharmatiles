Element · the document

point

A named point on the tile, in squares from the south-west corner. Pins, things, lines and regions use it by name.

On this page
  1. Writing it
  2. Reference
  3. Notes

Writing it

point knoll "(0.28, 0.72)"
line path { through southCenter knoll northCenter }
stack { base; dirt { pin top="groundHeight + 4" at=knoll } }

Reference

WrittenTakesWhat it does
point NAMEa nameIts name. Required. camelCase, declared once.
the value"(x, y)"Squares east and north of the south-west corner, on the tile. Required. Not a range: a declared point is fixed; a range goes where the point is written, in a line's through, a region's fill or an at=.

Built in on every tile, with no declaration: southWestCorner southCenter southEastCorner westCenter center eastCenter northWestCorner northCenter northEastCorner. The four edge lines are northEdge eastEdge southEdge westEdge, and edges is all four; tile is the whole tile, which is also what no at= means.

Notes

A point may also be written where a place is wanted, as the literal "(0.28, 0.72)": at="(0.28, 0.72)", fill "(0.5, 0.25)", through "(0, 0.38)". Today's "0.65,1" still reads. A point is flat: it says where, never how high.
