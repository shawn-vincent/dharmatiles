region

An area of a divided tile. Name the lines that bound it, then drop one or more fill points, like a paint bucket: the region is everything a fill point reaches without crossing a line. Elements act inside a region with in=.

Writing it

line shore wobble=5 { through "0,0.38" "1,0.42" }
region pool { bounded-by shore; fill "0.5,0.25" }
region bank { bounded-by shore; fill "0.5,0.75" }
stack {
    dirt in=bank
    water                    // fills its area up to the water level
}

Reference

WrittenTakesDefaultWhat it does
region NAMEa name—Its name, for in=. Required.
bounded-byline names—The lines that bound it.
filla point—A point inside it. Several fill points on different sides of a line join those areas into one region.

Notes

The whole tile is the default area, so an undivided tile needs no region. There is no union, intersection or difference: several fill points do that job. A region nothing fills is an error.
