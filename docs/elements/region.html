region

An area of a divided tile. Name the lines that bound it, then drop one or more fill points, like a paint bucket: the region is everything a fill point reaches without crossing a line. Elements act inside a region with at=.

Writing it

line shore wobble=5 { through "(0, 0.38)" "(1, 0.42)" }
region pool { boundedBy shore; fill "(0.5, 0.25)" }
region bank { boundedBy shore; fill "(0.5, 0.75)" }
region reach { within 5 of=shore }          // a strip beside the line
region dry { except pool }                  // everything but the pool
stack {
    base
    dirt { pin top=waterBedHeight at=pool }   // a region is a place a pin holds
    water                                     // fills its area up to its top
    grass at=bank                             // and where a coat grows, off the wet ground
}

Reference

WrittenTakesDefaultWhat it does
region NAMEa name—Its name, for at=. Required.
boundedByline names—The lines that bound it.
filla point—A point inside it, "(x, y)" or a point's name. Several fill points on different sides of a line join those areas into one region.
within MM of=PLACEa length, a place—Everything within that distance of a point, a line or a region: a disc round a point, a strip beside a line, a ring round a region (the region itself included). The length scales with the system. A range in it, within "[10 .. 20]" of=northEdge, draws the depth along the place: masses 6 to 15 mm long, each as deep as the range draws it (the same for the region and place whatever the seed), the middle of the range at both ends so runs butt.
exceptregion names—Takes those regions out. A region that only excepts starts from the whole tile.

Notes

The whole tile is the default area, so an undivided tile needs no region. The words add together: the fills, then each within, then except takes away. A region is flat, a footprint and nothing else; how high a body is over it is the body's top and pin. Bodies, grass and scatter take a region with at=; a point or a line is refused (dt::type). A region whose fill points all lie on its lines is an error.
