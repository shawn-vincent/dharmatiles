define

A named, reusable stack, written in a parts file and called like an element. Its param lines are the controls a caller can set. A definition whose stack is one thing is itself a thing: it can be placed with at= or scattered.

Writing it

// library/parts/grass.dtile
define lawn {
    param length "3.5..6.5"   // blade length along the ground, mm
    param height "1.5..2"     // how tall a blade stands, mm
    param clearings 1.5       // patches of bare earth per square
    param cover "100%"        // share of the ground grassed over
    stack {
        grass length=length height=height clearings=clearings cover=cover
    }
}

define long-grass {           // a definition can call another
    stack { lawn length="5..9" height="2..3" }
}

A tile then writes use "parts/grass" lawn and lawn cover="80%" in its stack.

Reference

WrittenTakesDefaultWhat it does
define NAMEa name—What callers write. Required.
param NAMEa default, or none—A control callers may set. Its default is checked as whatever control it fills (param length 10 is mm). With no default, the caller must give it.
stack—What it makes. Exactly one.

Notes

Place words given to the call (in=, at=) pass through to the elements inside. Expert controls, such as a tree's branch knobs, are allowed only in parts files. Definitions that call each other in a loop are an error (dt::loop). A tile has no params.
