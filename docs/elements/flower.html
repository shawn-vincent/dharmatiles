Element · thing

flower

One wildflower: a thin dome on a column, ringed by petal domes on cones. A flower is placed and sized like every other thing, a rock or a tree: one stands at= a point or somewhere in a region, and many are a scatter. Flowers listed above the grass are there when it grows, so the grass grows round them, never through them. A dirt listed after the flowers covers their feet, as written.

Writing it

dharmatiles version="1.0.0"

use "parts/grass" lawn

tile size="1x1" seed=7 {
    stack {
        base
        dirt
        scatter perSquare=4 { flower size="4dmm .. 6dmm" petals=5 }   // many, each its own size
        flower at="(0.5sq, 0.5sq)" size="5dmm"                        // or one, where you say
        lawn
    }
}

A scatter may mix flowers with rocks and trees (weight= picks each one); the flowers are placed last, clear of the others. Flowers keep to dry ground, inside the scatter's region and clear of rocks, trees and walls; a flower given a point must stand clear of the tile edge by its reach.
