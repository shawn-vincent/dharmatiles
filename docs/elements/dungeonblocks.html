Element · base

dungeonblocks

The DungeonBlocks base: one peg per 35 mm square, a column that drops into the socket of the piece below, following the published DungeonBlocks blank floor tile so dharmatiles tiles mix with commercial pieces. It is the default: dharmatiles build my.dtile builds for it.

Building for it

dharmatiles build my-tile.dtile                   # DungeonBlocks, the default
dharmatiles build my-tile.dtile --system db
dharmatiles build --all --system both             # every library tile, both bases

A document never names its base. The same document builds for either system; every size in it scales with the square.
