line

A line through points. Lines divide a tile into regions, and can wander off its points (wobble). A width makes it a strip that dirt, grass and cliffs follow with at=, and that a scatter fills.

Writing it

line shore wobble="5dmm" { through "(0sq, 0.62sq)" "(1sq, 0.58sq)" }
line trail width="9dmm" wobble="3dmm" { through south "(0.65sq, 1sq)" north }
line ring closed=#true wobble="2dmm" { through "(0.3sq, 0.7sq)" "(0.7sq, 0.7sq)" "(0.5sq, 0.3sq)" }
line stream { through westCenter eastCenter }       // the built-in points, by name

A line with a width is a strip: everything within half the width of it, wobble included. dirt at=trail, grass at=trail and cliff at=trail fill the strip like a region, and scatter at=trail spreads within half the width either side unless it writes its own reach. A wall follows the line itself, so a width does not widen it. A surface along a line with no width, or along a tile edge (which has none), is dt::type; for an edge write region rim { within "6dmm" of=northEdge } and at=rim. See demo/line-width.dtile.

Reference

WrittenTakesDefaultWhat it does
line NAMEa name—Its name, for boundedBy and at=. Required.
width=length (dmm)—Makes the line a strip of this width (above 0, up to 70dmm, scaled with the system); a dirt, grass or cliff at= it fills the strip, and a scatter reaches half of it either side.
wobble=length (dmm)0Lets the line wander up to this far off its points, keyed by the tile seed and the line's name.
closed=#true or #false#falseA loop: the last point joins the first (at least three points). The inside of a closed line is a region with fill.
throughpoints—The points, in order: "(across, down)" with units, counted from the north-west corner, a point's name (built in or declared), an edge word (its middle) or a corner word. Either half of a pair may be a range, weighted or not ("(0sq .. 0.1sq, 0.3sq .. 0.5sq)", "(bell(0.4sq .. 0.6sq), 0.45sq)"): that point is drawn once from the tile seed, keyed by the line's name and its place in the list, so another seed draws another line and editing one point moves no other. Required.

Notes

An element along a drawn line takes side=left, right or centre (the default), as you walk the line. Along a tile edge there is no side: a wall or cliff on an edge always stands inside the tile. Edges, corners and points are in the language guide.
