line

A line through points. Lines divide a tile into regions, and can wander off its points (wobble). Later, runs and surfaces will be built at= one, and a width will make it a strip.

Writing it

line shore wobble=5 { through "(0, 0.38)" "(1, 0.42)" }
line trail width=9 wobble=3 { through south "0.65,1" north }
line ring closed=#true wobble=2 { through "(0.3, 0.3)" "(0.7, 0.3)" "(0.5, 0.7)" }
line stream { through westCenter eastCenter }       // the built-in points, by name

Not built yet: width= and at= a line are read and checked, but dharmatiles build refuses a tile that uses them (check says which lines). For now a line divides regions.

Reference

WrittenTakesDefaultWhat it does
line NAMEa name—Its name, for boundedBy and at=. Required.
width=mm—Makes the line a strip of this width; an element at= it covers the strip.
wobble=mm0Lets the line wander up to this far off its points, keyed by the tile seed and the line's name.
closed=#true or #false#falseA loop: the last point joins the first (at least three points). The inside of a closed line is a region with fill.
throughpoints—The points, in order: "(x, y)" or "x,y" in squares, a point's name (built in or declared), an edge word (its middle) or a corner word. Required.

Notes

An element along a drawn line takes side=left, right or centre (the default), as you walk the line. Along a tile edge there is no side: a wall or cliff on an edge always stands inside the tile. Edges, corners and points are in the language guide.
