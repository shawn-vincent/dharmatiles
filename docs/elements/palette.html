Element · library file

palette

The paint: a flat colour per material, for 3MF files and the preview, and acrylic ramps from a dark basecoat to drybrushed highlights, blended by local relief. Copy it, change the colours, and pass it with --palette.

On this page
  1. Writing it
  2. Reference

Writing it

dharmatiles version="1.0.0"

// library/palettes/default.dtile
earth "#87553b"
rock  "#8892a6"
ramp earth "#381f16" "#5f3526" "#87553b" "#ae8063" "#cfab8c"
ramp water "#0f2e45" "#17607a@0.45" "#2fa0a0@0.72" "#8cdcc8@0.9" "#e0f5ee@1.04"
dharmatiles build my-tile.dtile --3mf --palette my-palette.dtile
dharmatiles preview my-tile.dtile --palette my-palette.dtile   # saving it repaints

Reference

LineMeans
MATERIAL "#rrggbb"The flat colour of a material: earth, connector, rock, water, grass, masonry, wood, leaf, flower.
ramp NAME tone tone …Paint tones from dark to pale. Raised detail takes the pale tones, hollows stay dark. A tone ending @0.45 sits at that place from 0 to 1; otherwise they are spaced evenly.
