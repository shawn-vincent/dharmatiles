reeds

Clumps of tapered reeds standing at the waterline and leaning out over the water. Write them in the bank region of a shore tile.

Writing it

line shore wobble="5dmm" { through "(0sq, 0.62sq)" "(1sq, 0.58sq)" }
region pool { boundedBy shore; fill "(0.5sq, 0.75sq)" }
region bank { boundedBy shore; fill "(0.5sq, 0.25sq)" }
region shoreBand { within "7dmm" of=shore }
stack {
    base
    dirt { pin top="[$waterBedHeight .. $groundHeight + 1dmm]" at=shoreBand; pin top="$waterBedHeight" at=pool }
    water                    // the pool fills over the dirt above it
    reeds at=bank            // stand along the shore, leaning out over the pool
    grass at=bank
}

Reeds stand along the shore: where the region they are in meets water. Each clump is several stems, each leaning toward the water.

Rules

What this element always does. A change to one of these is a change to the element.

  • Reeds are simple chunky blades that rise from one base and curve gently outward.
  • Tips are sharp but fairly blunt, blending smoothly into the blade. No cattails.
  • A clump roots by a height window on the land: where the land lies from 1.1dmm under the water's calm level to 0.2dmm over it. Reeds read the land and the library's calm height ($waterSurfaceHeight), never the water; the water reads the reeds.
  • A range of clumps or of stems gives every whole number an equal chance, the ends included.
  • Where a stem crosses the water's surface it is a thing standing in the water: its real section there sends the ripple rings round it.
