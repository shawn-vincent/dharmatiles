Element · surface

reeds

Clumps of tapered reeds standing at the waterline and leaning out over the water. Write them in the bank region of a shore tile.

Writing it

line shore wobble=5 { through "0,0.38" "1,0.42" }
region pool { bounded-by shore; fill "0.5,0.25" }
region bank { bounded-by shore; fill "0.5,0.75" }
stack {
    dirt in=bank
    reeds in=bank            // stand along the shore, leaning out over the pool
    grass in=bank
    ground in=pool level="water - 2.2"
    water
}

Reeds stand along the shore: where the region they are in meets water. Each clump is several stems, each leaning toward the water.

Rules

What this element always does. A change to one of these is a change to the element.

  • Reeds are simple chunky blades that rise from one base and curve gently outward.
  • Tips are sharp but fairly blunt, blending smoothly into the blade. No cattails.
