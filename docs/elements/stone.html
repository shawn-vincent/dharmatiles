Element · thing

stone

A rock with stone sizes, about 1–6 mm across. It is the same element as rock with a different default size; everything on the rock page applies.

On this page
  1. Writing it
  2. Reference
  3. Notes

Writing it

stone at="0.5,0.5"                       // one, there
scatter against=cliff perSquare=55 reach=4 { stone size="low(1..6, 11)" }

A thing is one of itself. Scattered against a cliff, stones are its scree. Many of them are a scatter.
