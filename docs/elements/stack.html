Element · the document

stack

The list of what a tile is made of: surfaces, things, runs, scatters and definitions, one per line. Order is free for solids: every solid is planned first, and everything grows round it. Order only decides which surface paints over which.

On this page

Writing it

stack {
    dirt level=edge { scatter per-square=40 { pebble } }
    cliff along=north height=35
    scatter against=cliff per-square=55 reach=4 { stone }
    grass                    // grows round the cliff and the stones, wherever it is listed
}

Reference

Every entry in a stack takes these, whatever it is:

WrittenTakesDefaultWhat it does
seed=a whole number—Pins this entry's randomness while the tile seed changes everything else.
id=a name—Names the entry among same-named siblings, for edits and diagnostics.
weight=a number1Only on a child of a scatter: its share of the mix.
place wordsin=, along=, at=, against=, side=: each element page lists the ones it takes.

Notes

The build plans the stack by what each element reads and writes: surfaces first, then the ground is lifted, then solids, and surfaces that grow round solids after them. A stack that asks for something nothing makes is refused with an error at the entry. The preview lists the stack under the tile's name, each entry linked to its page here.
