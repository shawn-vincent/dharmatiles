• The page checks for null: the editor's scripts and the site's live scripts (the example cards, the engine, the how-it-is-made demos) are now type-checked with strictNullChecks on, so a value that can be null or undefined must be handled where it is read. Optional parameters and the page's few variables that start as null carry real types; a lookup of an element the page always has goes through one helper (js/dom.js) that throws naming the element it did not find, and a canvas that gives no 2D context now says so instead of failing on the next line. Two print-list actions that would have thrown on a printer with no bed size now say so instead: the plate strip shows "no bed size" and pinning a piece explains why it cannot.
