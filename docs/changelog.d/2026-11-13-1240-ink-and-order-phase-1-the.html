• Ink and Order, phase 1: the editor’s one-rule fixes. Every text-like input and select takes the theme’s control style from one rule in theme.css that names the types it leaves out (the map piece’s Seed field, a number input, was the browser’s own: Arial, an inset border, square corners; a test fails on a bare input). A segmented control’s buttons share a track wider than they are (one rule, .seg > button), so Sort and Show no longer leave 114 and 71 px of empty track. Labels, values, stack numbers, swatches, names and chevrons sit on one baseline (the label was 2 px low, the stack number 7 px low, the About version 8 px high). Each fact is printed once: the title bar no longer repeats the tile’s size or a map’s totals, the context band no longer repeats the target, the name, the size or the totals, the status line no longer repeats the target or says not yet checked twice (draft · not yet checked · 1 full · 20 drafts). The floating more below pill and the Rename strip at the foot of the tile level are gone: the scroll shadow stays, and a double press on the document’s name in the crumb (or F2) renames it. A low-detail mesh is a draft wherever it is read (status line, messages, docs) and the Close camera is Close-up.
