• The warm check builds a torture set: the tests that run on every change build 32 small test tiles, chosen by measured line coverage of the engine (each the tile that runs the most lines the others do not, per second of building, to 99.5% of what every test tile runs), plus the odd shapes and the small tiles a test reads for one feature; two were made for it (1x1-grove-small, 1x1-reeds). dt-eval’s tests take 38 s, from 106. A warm test that reads any other test tile fails; such a test is a thorough_ one, and cargo xtask check --full runs the thorough tests and the whole-library sweep in one run of dt-eval’s test binary, so a tile is built once even there.
