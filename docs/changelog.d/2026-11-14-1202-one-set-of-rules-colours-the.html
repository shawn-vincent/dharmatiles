• One set of rules colours the tile language everywhere: dt_lang::highlight (no dependencies, beside the word tables) turns a document into coloured pieces: nodes, properties, strings with the $ names, numbers with their units and function calls inside them, keywords, comments and punctuation; a broken document colours as far as it reads and an unterminated string ends at its line. The terminal draws error snippets with it (miette’s highlighter hook; plain when piped or with NO_COLOR), the editor’s source pane asks the program for the pieces (/api/tokens) and lays them on as marks that move with the text, and cargo xtask docs colours every code block of the site, and reads the terminal’s own message on an error page back into the same classes, so the browser colours nothing and the editor’s and the site’s highlighters are gone. One mapping of classes to theme tokens (.tk-*) is in theme.css.
