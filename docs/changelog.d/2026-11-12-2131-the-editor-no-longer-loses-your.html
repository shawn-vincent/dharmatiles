• The editor no longer loses your work to itself: every document the editor writes (a tile, a map, a print list, a printer, the folder list) is written whole or not at all, through one function the code must use (a test fails the build if the server writes a document any other way); Undo of a map or print-list edit is refused, with the file’s current text, when the file changed since the edit (in another tab or your text editor), instead of writing the old text over it; the build call takes the session token like every other call, so a page of another site cannot make the editor build; dharmatiles mcp --http refuses a Host or Origin that is not the loopback, a request that is not application/json and a body over 4 MiB; a print list’s revision and its plan now come from one read of the file; the page lets go of the meshes of pieces it no longer shows; and the viewer’s render and view-change hooks are lists each part adds to, no longer one slot the last part overwrote.
