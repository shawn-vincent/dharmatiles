• One level shell for every document: a map’s levels slid by no animation while a tile’s did, because the map panel switched its own levels and the tile’s shell never saw them. Now one shell (editor/levels.js) shows the level you are at for every kind of document, from one table of levels (LEVELS in nav.js: the tile, an entry and a control; the map, a piece and a property) and slides by depth (slideBetween: deeper from the right, shallower from the left, none between documents). The map’s levels are views drawn into sections of the shell, like the tile’s, and keep their scroll, put the keyboard in the new level after a slide, take the arrow keys between rows, return the keyboard to the row you came from, and honour reduced motion by the same code; ⌘] goes back down a map’s levels as it does a tile’s. The map panel’s own level switching is deleted, and a test fails if a view shows, hides, animates or names the level on screen.
