• The tile's plan is typed: a document's plan, which the page reads for its frame, stack, plates and inventory, is one type, TilePlan, with a variant for a tile, an STL file, a print list or map and the inventory; the plates' panel, its kinds, layout and pieces, the printer rows and the inventory's rows are typed too. Every writer constructs it (nothing is patched in place, nothing is converted to camelCase on the way out), the program reads its fields where it recorded a print, and the page reads the generated type (js/api.d.ts), with tsc checking more of the files that read it. An STL file's one stack line is now a stack item like any other.
