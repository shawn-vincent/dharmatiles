• The ledger: ledger.kdl lists every known violation of the language principles, and tests read their known exceptions from it by id (Ledger::expect): a case fixed must leave the file, a new broken case must not appear in it except through an audit commit that changes ledger.kdl alone. cargo xtask check holds that, and cargo xtask release wants an audit newer than the last tag. --no-tests is now --skip tests "reason" (and --skip audit "reason"), the reason written into the changelog entry.
