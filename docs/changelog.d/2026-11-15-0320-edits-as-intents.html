• Edits are intents, checked by the program: every edit of a tile, a print list or an inventory goes through one apply, which reads the text again and refuses an edit that would add a mistake the old text did not have (the page is told which mistake, as a 422, and nothing is written); the description of a tile is set with about and the program writes the string, so the page no longer quotes KDL; a copy of a library tile points its use lines at the library with one edit for each use the decoder found, not by walking lines of text; a point, a value or a slider dragged on the sheet steps at the low tier and the step that ends it drafts as usual; and a mesh goes to the page as shared vertices, indices and one palette index for each face, about a quarter of the bytes of a draft (the shore example’s draft reply went from 19.7 MB to 4.7 MB), with the same STL and the same hashes.
