• dharmatiles fix mends tiles the language has outgrown: dharmatiles fix tile-or-folder collects every mistake that carries a fix (dt::seam, dt::near-edge, dt::edge-range, a misspelt word with a near one, an old control spelling, a number on a corner word) and shows the change with the millimetres a point moves on the target’s square; --write writes it, after which it checks again and repeats until no fix applies. A mistake with no fix is reported and the exit status is 1. A fix is data made once where the mistake is made (Fix in dt-doc, with moved for a moved point), the help is made from it, the editor’s button and the command line lay it in through the one edit engine (Op::Fix in dt_doc::ops). A corner word written with a number (nw(2)) and a one-square side word with a wrong number now carry their fix too.
