• An earlier build shows while a changed tile builds: change a tile (or a part it uses) and open it in a fresh run, and the cache’s older build of it for the same target shows at once, the status line says rebuilding, and a message names the build it is; the new build replaces it, and a failed one takes it off. dharmatiles cache previews builds the draft of every library tile, thinned to what the view shows, into the cache (or, with --into, into a folder an install copies into it), so the library has something to show the first time; a tile with only a preview shows it the same way.
