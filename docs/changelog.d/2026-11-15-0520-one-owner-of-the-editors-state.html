• The editor has one owner of state: the editor's server holds the tiles, the event stream, the places, the target and the build queue on one thread, and the connections and workers send it commands, so there is no lock order to keep. Build workers wait on it for a job instead of waking every 150 ms, a save the editor makes tells it at once, and the one polling left (every 150 ms) is for files changed outside the program.
