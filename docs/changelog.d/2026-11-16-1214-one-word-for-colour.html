• What changed: a print is single or multicolour, said one way everywhere. The setting is colour in a .dmap's plates line (it was mode), in an inventory.dinv line (the value was multi), and as --colour on dharmatiles plates (it was --mode) and on dharmatiles inventory, with the values single and multicolour. One type (dt_lang::Colour) holds it in the program, in the page's types and on the wire. A document that still writes mode= or colour=multi is refused with a fix that writes the new word, and dharmatiles fix --write FILE now mends .dmap and .dinv files as well as tiles; --mode and --colour multi are refused naming the new spelling.
