• The site’s sliders ask the program to edit, they do not write text: a live card’s slider used to put a number into the source itself (writing the quotes and counting bytes). It now sends the engine a typed edit, the node’s id and the fingerprint of the text it was read at, and the engine makes it with the same function the editor’s /api/edit uses (dt_service::edit). A test scans the site’s scripts, like the editor’s, and fails on text made by hand.
