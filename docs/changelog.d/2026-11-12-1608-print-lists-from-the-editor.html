• Print lists from the editor: New print list in a folder you own writes an empty .dmap for the printer last chosen; Add to print list on a tile's level (and in a tile row's menu) adds one more copy to a list or a new one, raising the count of a piece already there at the same seed and system; the plates' panel lists the pieces with −, + and ✕; every change is an edit of the list's text with Undo, shared with the inventory's Reprint. A print list has the Tile and Source switch: Source edits and saves the KDL, mistakes shown at their text by the print-list reader, and a save lays the plates out again.
