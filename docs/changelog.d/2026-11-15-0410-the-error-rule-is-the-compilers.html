• The error rule is the compiler's: clippy now refuses Result::ok, unwrap_or, unwrap_or_default and the like, and every #[allow] needs a reason (live ones are #[expect], so a stale one fails). Each existing site now travels, is infallible by construction (dt_value::idx, lock_unpoisoned), or carries its reason; a scan test caps the marked silences. The MCP server reads HTTP with the preview's one parser. Failures that were hidden now show: the browser build reports a document that does not check as its diagnostics (not a silent stage count of one), a map whose tile document does not parse is an error, a printer scan with no home folder is refused, a plate list whose tile cannot be read again names the tile, the preview that cannot read its own address stops with the error; and no silence is marked undecided any more.
