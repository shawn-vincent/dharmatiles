• The editor page works out no byte offset and reads no KDL quoting: the program sends each written control with its whole span (name through value), its value and the value as words (quotes off, escapes undone), so the sheet no longer subtracts name lengths from spans, unquotes values or writes quotes into a size field.
  • The places tests send the routes' own request types: each call in the places tests is the route's request type, and only the test of a malformed request keeps a raw body.
  • A poster's map says its square size: posters/KEY.map.json is a PosterMap (the target's square in mm and the tile's map), so the overlay on a poster no longer assumes a DungeonBlocks 35 mm square; posters made before this change are made again (delete docs/posters/*.map.json, then cargo xtask examples).
