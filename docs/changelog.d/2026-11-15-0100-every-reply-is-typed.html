• Every reply of the preview server is typed: a route's answer is its response type serialized once, and a refusal or failure is the ErrorBody itself until it is written to the socket, so no reply is a serde_json::Value patched by key. A 409 for a map carries its scene because the reply is built with it, and the server's check on a 5xx reads the error body as its type. The server's own tests of these replies read the route's response type, not keys; nothing the page reads changed.
