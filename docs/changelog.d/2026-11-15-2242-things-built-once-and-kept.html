• Things are built once, copied and kept: a scatter can say variants=K, and then each thing it places is one of K variants, each built once and copied, turned about its own axis, to every place it stands (a cover of two thousand pebbles builds twelve with variants=12). Unset, every placement is its own draw, as before, and the tile builds the same bytes. A rock is now built in its own frame and set down by one rigid move (Body::set_down), the only path from a rock to the scene, and that body is kept by its own key, made by the same key maker as a tile's (make_thing_key: the canonical form of the stone, the build target, the tier and the engine), on the same store: a tile rebuilt after an edit that touches none of its rocks reads them from the disk cache or the browser's memory instead of building them, and the build record says how many things were built, copied and read (things). Flowers and trees stay built where they stand: a flower moved from the origin differs by a hair's breadth, which moved a meadow's gate repairs past their budgets, and a tree's sink, footing and top= read the tile.
