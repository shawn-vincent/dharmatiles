• Add a folder with the Mac’s chooser: Add a folder… at Places shows the system folder chooser (the program shows it; the page never sends or types a path), keeps the folder in places.json in ~/Library/Application Support/dharmatiles/ ($DT_SETTINGS for another folder), and lists it at once and after a restart.
