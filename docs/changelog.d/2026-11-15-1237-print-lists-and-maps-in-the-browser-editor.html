• Print lists and maps in the browser editor, with no program: starting a print list or a map, putting a tile in it, changing a piece's copies, place, turn, height, seed or pin, removing it, and Undo and Redo are the service's own verbs now (dt-service's list_calls and map_calls, written once on a host the program and the editor's web worker both are), so the editor in a web page answers them as the program does: the same refusals for a file that moved on (with the map as it now reads), for a list that does not read (with its mistakes), and for a piece or square that is not there. A printer's profile is looked up through one question, dt_eval::Profiles (the disk in the program, the library the page was handed in the browser).
