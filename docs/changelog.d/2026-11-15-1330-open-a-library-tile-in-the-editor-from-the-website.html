• Open a library tile in the editor from the website, with no program: each shipped tile listed under In the library on an element page has an Open in the editor link, which opens the browser editor (served beside the pages, with the engine the cards already run) on that tile: it builds in the page, can be changed and copied into My tiles, filed in folders, and rebuilt for OpenLOCK, and nothing is sent to a server. cargo xtask editor --site <dir> lays the whole site out for a static server; --page lays only the editor's page, which the site's build adds beside its pages. The page's own files are now named relative to it (so it works in a folder of the site as at the root of the program), and ?site= says where the site's folder is.
