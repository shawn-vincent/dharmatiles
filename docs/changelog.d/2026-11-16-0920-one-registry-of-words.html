• One registry of words: every word of the tile language (keywords, controls, choices, functions, units, elements) and of the program (the service’s verbs, the command line’s commands and flags, file kinds) is a row of one table, dt_lang::words, with its meaning and its kind. The decoder reads a keyword by its constant, not a string, and the guide’s cheat sheet now lists the keywords and says what each function and weighting means from the same rows. Vocabulary tests fail on a word used and not registered, a word registered and not used, a keyword written as a string in the decoder, and a word that does two jobs; the twenty that do today (top is a height and a wall’s crenellations, size is a tile’s squares and a rock’s width, line is a node and a printer’s line width, and so on) are listed in ledger.kdl as collision:<word>.
