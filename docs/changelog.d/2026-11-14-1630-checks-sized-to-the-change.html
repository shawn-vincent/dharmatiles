• Checks sized to the change, and one heavy job at a time: cargo xtask check runs the checks a branch’s changes can fail, chosen from its diff against main (fmt and clippy for Rust, the tests of each changed crate and of every crate that depends on it, the page’s tests, docs --check, and the sweep of only the library tiles that use a changed element); --full runs everything. cargo xtask sweep grass sweeps the tiles that use grass (DT_BASELINE_ONLY), and the sweep, contact sheets, pictures and the browser engine take one lock shared by every worktree (cargo xtask heavy for any other command). A fresh build folder builds Manifold once, from a shallow clone of its tag: the browser’s Manifold feature no longer reaches the host build, where it made a workspace test run compile Manifold and the engine a second time. Unreleased changes are one file each under docs/changelog.d/, which a release folds in, so two branches never edit the same lines; cargo xtask regen writes every generated file again after a rebase.
