• A property on a thing param is checked as on the thing itself, and its groups work: what is written on the entry that calls a thing param (piece size=5, crown width=…) is now typed once the call says which thing it is, by the decoder’s own function, so it gets the same unit and kind check, range, words and refusals, with the same code and words, at the line in the definition (piece size=5 is dt::unit as pebble size=5 is). A tree’s trunk, crown, leaf and branch controls can be written on a thing param standing for a tree. No tile changes.
