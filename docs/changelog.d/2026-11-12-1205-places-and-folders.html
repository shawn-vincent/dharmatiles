• Places and folders: the top of the panel is Places (My tiles, the folders you added, the Library, the Tests) and the levels under it are folders: a place opens to its subfolders and then its tiles (name, size, a picture of the footprint, a dot for the build), a subfolder is another level, and the crumbs run Places › My tiles › dungeon › combo › tree › trunk height with the same slide and a strip that says how many tiles the folder holds and where it is on disk. The old tile browser and its root tabs are gone: the crumb, ‹, ⌘[ and the start with no argument all land on these levels (the start with a file named still opens it). A folder level is in the address (#place=…&dir=…), a filter searches the whole place, and the folder level lists documents by kind from one table.
