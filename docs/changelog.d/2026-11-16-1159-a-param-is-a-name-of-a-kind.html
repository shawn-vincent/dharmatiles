• A param is a name of a kind: a param's kind is its kind=, else its default's (param n 3 is a plain number, param w "5dmm" a length, param leaf pebble a thing), and it is never read off the way the param is used. A param with neither is dt::kind, saying to write kind=, so a param that only a scatter's child or a control used to decide now says its kind. Being a name, a param goes anywhere a let of its kind may: a part's count="n + 1" works in check and in build (it was refused in both), as does size="w * 2". Each use is checked against the kind where it is written, in the words of every kind mistake (rock size=n with param n 3 says n is a plain number and rock size wants a length), and every caller's argument at the call. A param holds a number, a thing or a layer, so a param that held a word (param shape angular filling a shape) is refused: write the word where it is used.
