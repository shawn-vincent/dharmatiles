• The browser editor keeps what it built and draws the debug layer on a full build: in the editor that runs in a web page with no program, a tile whose source, parts and build target have not changed since it was built is read from the builds the page keeps, not built again (put a change back and the tile is there at once; its build record says it was read), and switching the debug layer on for a built tile builds it once more with the layer’s marks, as the program does. The program and the browser now keep and read builds with one function. cargo xtask parity --service, which holds the browser’s service to the program’s, takes 30 seconds instead of 150.
