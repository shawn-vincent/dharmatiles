• The program and the tests build the engine once: the test build and the program's build gave the engine different features, so every engine change compiled dt-eval through dharmatiles twice. Now no engine feature is on by default (Manifold's parallelism follows the target), wasm-bindgen is a dependency of the browser build only, the crash switch the exit-code tests use is a leaf crate of its own (dt-crash-switch), and the third-party features the tests' tools turned on are asked for in the program too. After an engine change the program's build compiles only its own crate.
