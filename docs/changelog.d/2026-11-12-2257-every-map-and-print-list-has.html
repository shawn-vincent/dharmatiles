• Every map and print list has one owner: the program numbers each document’s states (docRev, a number that only rises, bumped by every write it makes and by a change it finds on disk), writes each document under a lock of its own, and says the number in every answer and every event; the page takes a state only if its number is newer, every edit says the number it was made against and a file that moved on is refused with a 409 and its current state (nothing is overwritten), and the four-second hold of a map’s scene is gone. Pieces are named by id, never by position (the first edit of a file whose pieces have no ids writes one on every piece in the same write and says so once), the selection is a set of ids, and the panels’ buttons hold ids and look the piece up when they run, so two quick turns are two turns. Undo and Redo are one history for the page (text steps, the map’s changes, print-list counts, pins, the printer, the Source’s saves), driven by the title bar and ⌘Z / ⌘⇧Z, each step made against the revision the history left; the title bar’s chip and the status line read the document’s own state. A test runs hundreds of random sessions of actions with answers and events arriving in any order and checks that every view equals a fresh working-out from the newest state.
