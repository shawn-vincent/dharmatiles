Surface variants, old to new

Shawn asked: "I like the look of the last one, but I'm curious what the other ones, how they worked, and what's different about the new ones." This page answers that for each kind of surface. Each kind has a family tree, a pipeline for every variant, renders recovered from git history or rebuilt from existing STLs, a comparison table, an explanation of what changed in the version he likes, and the one parameterized definition the variants reduce to.

Click any node in a family tree to see how that variant worked. Most images are renders committed at the time and recovered with git show. Some were rendered for this analysis from STLs already on disk, with over-limit faces in red; their captions say so. Variants with no surviving output are marked.
