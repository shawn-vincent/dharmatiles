Session history

Dated reviews, requirement interviews and session logs, 30 May – 5 July 2026, plus the loose markdown notes from the early library. All markdown.

  • Leaf placement: the complete history (3 Jul) — the method later reused for every look: requirements interview, guarantees by construction, render-judged iterations.
  • Grass greenfield requirements (3 Jul), rocks greenfield (3 Jul), walls greenfield (4 Jul), foliage greenfield (2 Jul).
  • Walls and rocks refactor review (5 Jul) — the plan behind src/dharmatiles/stone/.
  • Leaf placement sessions, 19 Jun – 3 Jul: FDM design space, debug pipeline, cluster baldness, rendering history, contact angle, systematic development protocol, floating-leaf check, meridian arcs, code review, phi distribution, jitter fixes, greedy lowest-first, deconfliction, greedy vs meridian, organic placer performance.
  • Architecture and code reviews, 30 May – 18 Jun: grass tile, architecture, OpenLOCK compliance, OpenLOCK regeneration, performance, gamer perspective, grass requirements, DRY and performance, full review (8 Jun), full review (9 Jun), performance and CLI, tile spec, DRY, architecture direction, elegance, strategic, technical, tree terminology rename.
  • Early library notes: floppy grass algorithm and grass requirements, design, behaviour (the field-simulation grass, replaced by mound-thatch); grass scene v1 (the heightmap-PNG pipeline); point-cloud tree and CloudTree mesh (replaced by the current skeleton and closed solid branches); browser Python viability (a Pyodide exploration, 24 Jun).
