The result

dharmatiles version="1.0.0"

// Every build is held to the printability gate: watertight, nothing lost, and no more than a
// sliver of the underside past 55 degrees from vertical.  Boulders lean out the most.
tile size="1x1" seed=5 {
    stack {
        base
        dirt
        scatter count=3 { boulder size="6dmm .. 10dmm" }
    }
}

Say it plainly

A printer can lean each layer a little past the one below, but not much. Every element is built to keep every downward-facing surface within 55° of vertical; small patches may reach 65°, and no more than 0.1% of the underside may be past either.

You do not write the gate; it is a test the program runs on the built tile. When a tile fails it is fixed where the geometry is made, never by loosening the test, and the picture paints the faces in question orange and red.

The rules

Overhang is held to 55 degrees, with small patches to 65

Faces between 55° and 65° from vertical are the band, painted orange and allowed up to 0.1% of the tile’s downward-facing area; faces past 65° are painted red and allowed only up to another 0.1%. Both angles are the printer profile’s overhang and steepest. See No supports for what the angles mean on a printer.

A tile must be watertight, with nothing lost

After the mesh is reloaded at the precision an STL stores, it must be watertight, and every part must be joined to the tile. A tile that fails is reported as failed, with exit code 3, though its files are still written for inspection. The full list is on the rules page.

The printer profile sets the floors, not the tile

The thinnest wall, the layer height and the narrowest gap that stays open come from the printer profile (library/printers/default.dtile), written in printed units. Elements apply them after scaling, so a scaled blade or branch is never thinner than what prints. See units.
