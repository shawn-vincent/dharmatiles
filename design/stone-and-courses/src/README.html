Stone and Courses

The page and its decisions log are built from this folder alone, plus the shared rock library (../../rock/src/ in the repo). Needs python3 and node.

python3 build.py            # writes ../index.html and ../decisions.html, and MANIFEST.txt
  • text/ the page: _order.txt is its order and the four groups; steps/ one file per step; nav.json the contents list. {{name}} is filled from data/measured.json; {{TABLE:name}} is a table made from it. A missing name, or a text file over 120 KB, stops the build.
  • decisions/ the decisions log: entries.html and the old measurements kept as written.
  • js/ the engine (engine, graded, rock, union), the viewer (ui), the one table of controls (controls), the components (widgets), the presets and the explorer.
  • css/, img/, vendor/ (Manifold). data/measured.json is written by the sweep, never by hand.
  • MANIFEST.txt every file the last build read.

The identity sweep that wrote measured.json (114 builds, hashes held against a baseline) lives with the design work, not here.
